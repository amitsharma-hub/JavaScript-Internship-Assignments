## 💻 Capstone Mini Project: Product Inventory Dashboard

A simple interactive dashboard built with JavaScript to manage product inventory and calculate inventory statistics.

### Features
- Add a new product using user input.
- Validate product names and prices.
- Categorize products as Budget, Standard, or Premium.
- Calculate the total inventory value.
- Filter affordable products priced under $200.
- Generate a formatted product report.

### 🛠️ Technologies Used
- HTML5
- JavaScript

### ▶️ How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the product name and price when prompted.
4. View the inventory details and total value on the page.
